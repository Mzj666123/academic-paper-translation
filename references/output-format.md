## 1. 默认输出格式

**默认输出 PDF 格式**，保存到桌面。

转换流程：Markdown 翻译稿 → Word 中间文件 → 最终 PDF
使用脚本：`scripts/md_to_pdf.py`

命令：
```bash
python scripts/md_to_pdf.py input.md output.pdf
```

## 2. 页面与字体规范

### 页面设置
- 纸张：A4
- 页边距：上下 2.5cm，左右 2.8cm
- 页码：页脚居中

### 字体规范（全文统一，禁止混排）

| 层级 | 字体 | 字号 | 对齐 | 说明 |
|------|------|------|------|------|
| 论文标题（一级） | 黑体 | 16号 | 居中 | 加粗 |
| 章标题（二级） | 黑体 | 14号 | 左对齐 | 加粗 |
| 节标题（三级） | 黑体 | 12号 | 左对齐 | 加粗 |
| 正文 | 宋体 | 12号 | 两端对齐 | 首行缩进2字符，1.5倍行距 |
| 表格表头 | 黑体 | 10号 | 居中 | 加粗 |
| 表格内容 | 宋体 | 10号 | 居中 | - |
| 图表标注 | 宋体 | 10号 | 居中 | - |
| 公式 | Times New Roman | 12号 | 居中 | 变量符号保留英文 |

**重要原则**：正文段落内字体完全统一，不得随意加粗或变更字体。需要强调的术语首次出现时也不例外，保持宋体即可。

## 3. 图表与公式规范

### 图片插入格式
- Markdown 语法：`![图题翻译](images/图片文件.png)`
- 图片自动居中，宽度自适应页面（14cm）
- 图题在图片下方，宋体 10号，居中
- 示例：
  ```markdown
  ![图1：永磁同步电机结构示意图](images/page3_img3.png)
  ```

### 表格格式
- 使用 Markdown 表格语法
- 自动转为三线表格式
- 表头黑体加粗，内容宋体

### 公式格式
- **简单公式**（单行、无嵌套）：用 `$$...$$` 标记，自动渲染为标准数学排版
- **复杂长公式**（嵌套分数、多重上下标、方括号嵌套）：直接从原 PDF 裁剪为图片插入，保证和原文完全一致
- 公式居中，编号右对齐
- 判断标准：嵌套超过2层（分数套分数）、多层方括号/根号嵌套 → 用图片
- 简单公式示例：
  ```markdown
  $$C_0 = \frac{1.778 \times 10^{-11} \pi m_1}{\ln\left(\frac{r_{a1}}{r_{a2}}\right)} \tag{1}$$
  ```
- 复杂公式示例（从 PDF 裁剪后插入）：
  ```markdown
  ![公式4：励磁绕组磁动势](images/formula_4.png)
  ```

### 参考文献
- 整体保留原文，不翻译
- 正文中的引用标注保留原文格式

## 4. 全局术语库

**位置**：`C:\Users\all\Desktop\学术翻译术语库.xlsx`

### 结构
| 列 | 说明 |
|---|---|
| 英文术语 | 唯一键，不重复 |
| 中文译名 | 标准译法 |
| 累计出现频次 | 所有翻译任务累计出现次数 |
| 术语类别 | 核心概念 / 方法 / 设备 / 缩写 / 材料 / 结构 |
| 首次来源 | 首次出现的论文名称 |

### 使用规则
- 每次翻译任务开始时：读取术语库，加载已有术语译名
- 翻译过程中：优先使用库中译名，保证一致性
- 翻译完成后：抽取本文新术语，合并写回库中（去重、频次累加）
- 用户可随时打开桌面的 Excel 文件查看和编辑术语库
